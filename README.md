# AMRUTKALP™ — Pure Ayurvedic Herbals

An e-commerce storefront and digital dispensary for **AMRUTKALP (Pure Ayurvedic Herbals)**, built with React 19, TypeScript, Vite, and Tailwind CSS.

Features the authentic master studio photograph of **Sanjivani Pure Himalayan Shilajit (20g)**, classical Ayurvedic formulation monographs (Amrutvati #आराम होगा तो काम होगा), and the public **₹5,51,000 Authenticity Challenge**.

- **Storefront & Catalog**: Filterable remedies, live search, and sorting.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

## 📦 How to Upload to Your GitHub Account

Because this AI environment cannot access your private GitHub credentials, you can push this repository to your GitHub in 3 steps:

### Option A: Push directly from your machine

1. Create a new empty repository on [GitHub](https://github.com/new) named `amrutkalp-website`.
2. In your terminal, run:

```bash
git remote add origin https://github.com/YOUR_USERNAME/amrutkalp-website.git
git branch -M main
git push -u origin main
```
