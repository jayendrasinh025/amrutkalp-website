# AMRUTKALP™ — Pure Ayurvedic Herbals

An e-commerce storefront and digital dispensary for **AMRUTKALP (Pure Ayurvedic Herbals)**, built with React 19, TypeScript, Vite, and Tailwind CSS.

Features the authentic master studio photograph of **Sanjivani Pure Himalayan Shilajit (20g)**, classical Ayurvedic formulation monographs (Amrutvati #आराम होगा तो काम होगा), and the public **₹5,51,000 Authenticity Challenge**.

# 3. Build for production
npm run build

## 🌐 Free Live Hosting on GitHub Pages

This repository is pre-configured for GitHub Pages:

### Method 1: Automatic GitHub Actions (Recommended)
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. That's it! GitHub will automatically run the build and publish your site at:
   `https://jayendrasinh025.github.io/amrutkalp-website/`

### Method 2: Deploy from `/docs` folder
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch **`main`** and folder **`/docs`**, then click **Save**.
4. Your website will be live in ~1 minute without needing any build tools!
